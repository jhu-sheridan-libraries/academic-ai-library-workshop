# Citation

If you use this repository, the workshop application, or its instructional materials in a publication, presentation, course, or other public work, please cite it as follows.

## Preferred citation

Miklovic, Steven J. (2026). *Agents and Skills with Claude — A Walkthrough* (Version 0.0.1). The Sheridan Libraries, Johns Hopkins University. https://github.com/jhu-sheridan-libraries/academic-ai-library-workshop

## Citing a specific release

For reproducible work, cite the workshop-materials release or Git commit used in your work rather than the moving repository URL alone. Add the release tag or commit identifier to the citation and include the date you accessed it.

Example:

> Miklovic, Steven J. (2026). *Agents and Skills with Claude — A Walkthrough* (workshop-materials release, accessed 2026-08-25). The Sheridan Libraries, Johns Hopkins University. https://github.com/jhu-sheridan-libraries/academic-ai-library-workshop/releases/tag/workshop-materials
